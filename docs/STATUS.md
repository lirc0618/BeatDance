# 当前实施状态 v0.3

## 已完成

- 产品已从“整舞 AI 分析”重构为“Feed 动作卡点搜索”；
- H5 已使用原生暂停事件和 `currentTime`；微信小程序使用播放器上报的最近时间点，并在 `pause` 事件提供时间时优先采用；
- 服务端自行校验 Feed 时长、读取暂停点附近真实帧，并把前后 1.5 秒动态片段用于本次姿态对齐；
- 支持手部、脚步、拍点、自动判断四种关注点；
- 诊断结果包含一个主导卡点、搜索词和可点击的 Top-3 抖音拆解搜索；
- 四个动作共 20 条教学记录已从 Python 画像拆到独立内容矩阵，并记录许可与本地保存策略；
- 保留镜像校正、骨架归一化、DTW、节奏/路线/幅度诊断和二练验证；
- 已打包 13 条开放许可动作视频，并保留可复现下载目录与完整署名；
- 支持通过管理员导入接口和 CLI 动态新增或替换 Feed，并按配置限额持久化到 `data/`；
- 真实视频解码、时长校验、随机帧读取、FFmpeg 归一化全部通过；
- Python 3.11 下的 MediaPipe 33 点真实视频端到端链路已通过；
- 四个动作均使用与 Feed 同源、同动作的短参考；
- 错误首练到正确二练已按首练主卡点指标验证改善；
- 后端算法、教学内容矩阵、动态 Feed 导入、暂停解释、参考代际切换、下载元数据与脚本回归测试、真实 API 验收和 H5 浏览器闭环通过。
