# MVP 验收清单

## 功能

- [x] 三个动作在 `/actions` 显示为 `reference_ready=true`（开放样例工程参考）
- [x] Feed 视频只有在真实暂停后才解锁“分析这一秒”
- [x] 暂停结果包含服务端校验的时间点、前后 1.5 秒真实帧和动作阶段说明
- [x] 暂停阶段先返回背面、慢速、局部三种拆解，再进入个人模仿诊断
- [x] 上传 3 秒以下视频会被拒绝
- [x] 上传 8 秒以上视频会被拒绝
- [ ] 无人/多人/严重遮挡视频给出可读重拍提示
- [x] 正常视频返回主要问题、三项指标、微练习
- [x] 返回参考/用户关键帧对比图
- [x] 镜像视频能自动校正并显示提示
- [x] 豆包未配置或超时不阻断分析（已验证未配置降级）
- [x] 第二次上传显示改善结果
- [x] 删除接口能删除结果与对比图

## 稳定性

- [x] 三个动作各连续运行 5 次
- [ ] 两台不同手机完成微信小程序上传
- [ ] H5 在微信内置浏览器和普通浏览器可用
- [x] 单次 CPU 分析不超过 25 秒（目标）
- [ ] Docker 重启后参考动作和结果仍存在

## 诊断标定

建立表格记录每个测试视频：

```text
视频 | 预期类型 | 实际类型 | 预期部位 | 实际部位 | 是否稳定 | 耗时
```

必须优先保证：

- 同一视频重复分析时主要问题一致；
- 明显节奏错误不被长期误判为角度；
- 镜像校正不会反复选择错误方向。
