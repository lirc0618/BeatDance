# MVP 验收清单

## 功能

- [x] 五个动作在 `/actions` 显示为 `reference_ready=true`（授权样例工程参考）
- [x] 可通过单个命令新增第 4 条 Feed，同 ID 可替换且失败不会破坏旧动作
- [x] Feed 视频只有在真实暂停后才解锁“分析这一秒”
- [x] 暂停结果包含服务端校验的时间点、前后 1.5 秒真实帧和动作阶段说明
- [x] 暂停阶段先按动作返回三条专属拆解，再进入个人模仿诊断
- [x] 上传 3 秒以下视频会被拒绝
- [x] 上传 8 秒以上视频会被拒绝
- [x] H5 上传前展示横竖屏、尺寸和清晰度检查结果
- [x] 上传其他舞蹈时停止技术纠错并给出可读的动作不匹配提示
- [x] 关注点细分为手势、手臂、核心、脚步、节奏和 AI 自动
- [x] 手势不可见时要求重拍，不用手腕数据冒充逐指评分
- [x] 横竖屏 Feed 完整显示并使用稳定封面与模糊背景补位
- [x] Feed、暂停预览、教程和结果回放同一时间只播放一条
- [ ] 无人/多人/严重遮挡视频给出可读重拍提示
- [x] 正常视频返回主要问题、三项指标、微练习
- [x] 对 3–8 秒片段的全部采样帧进行 DTW 对齐分析
- [x] 返回整段匿名骨架回放，红色标出主要卡点
- [x] 返回参考/用户关键帧对比图
- [x] 五个动作各有 5 条外部教学记录，并返回至少 3 种不同教学视角
- [x] 25 条教学记录统一标记为 `permission_granted + local_allowed`
- [x] `make content-check` 校验内容覆盖、许可状态和本地文件路径
- [x] 镜像视频能自动校正并显示提示
- [x] 豆包未配置或超时不阻断分析（已验证未配置降级）
- [x] 反馈先展示一句总体评价，再指出一个重点问题和改法
- [x] 第二次上传显示改善结果
- [x] 删除接口能删除结果、骨架回放与对比图

## 稳定性

- [x] 五个动作各连续运行 5 次
- [ ] 两台不同手机完成微信小程序上传
- [ ] H5 在微信内置浏览器和普通浏览器可用
- [x] 单次 CPU 分析不超过 25 秒（目标）
- [ ] Docker 重启后参考动作和结果仍存在

## 诊断标定

建立表格记录每个测试视频：

```text
视频 | 预期类型 | 实际类型 | 预期部位 | 实际部位 | 是否稳定 | 耗时
```

必须优先保证：

- 同一视频重复分析时主要问题一致；
- 明显节奏错误不被长期误判为角度；
- 镜像校正不会反复选择错误方向。
