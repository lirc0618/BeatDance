# PRD：对拍

版本：MVP 0.2（差异化重构）  
团队 / 开发窗口：4 人 / 30 小时  
主交付：微信小程序 + 公网 H5 + FastAPI + Skill

## 1. 产品定义

用户在短视频 Feed 中刷到一个想学、却看不懂的动作，暂停在具体时间点并点击
“分析这一秒”。系统先读取暂停点前后动作上下文、解释这一阶段，再让用户表达
关注手部、脚步还是拍点并上传 3–8 秒模仿。系统：

1. 截取暂停点前后 1.5 秒，并与用户模仿对齐；
2. 定位节奏、路线、幅度中最关键的一处卡点；
3. 用该“失败状态”搜索最适合的背面、慢速、局部或新手拆解；
4. 用户再练一次，验证该卡点是否改善。

一句话：**不是评整支舞，而是把 Feed 里没看懂的半秒，搜索成适合你的学法。**

## 2. 为什么重构

市场已有产品覆盖整舞视频存储、自动同屏对齐、逐帧 AI 分析和练舞统计。若继续以“参考视频 + 模仿视频 + AI 纠错”为完整定位，差异不足。

本项目将已有姿态分析能力降为底层工具，把产品核心改为：

- 触发对象：Feed 中被暂停的短动作片段；
- 搜索对象：用户当前的动作卡点，而非动作名称；
- 结果形态：不同视角和难度的短视频拆解，而非长分析报告；
- 完成标准：搜索结果被练习并通过二次上传验证。

## 3. 用户真痛点

用户不缺“完整舞蹈教程”，缺的是：

- 不知道刚才那半秒手脚如何衔接；
- 能看懂原视频，但不知道自己卡在拍点、路线还是幅度；
- 搜“动作名”得到大量内容，却不知道该看背面、慢速还是局部；
- 看完教学后仍无法判断自己是否真的修正。

用户已有自然行为：暂停、拖动进度条、调慢速、看评论区、搜索“求背面 / 求脚步 / 求慢放”。产品只接住该行为。

## 4. 与整舞 AI 教练的硬边界

| 维度 | 整舞 AI 教练 | 对拍 |
|---|---|---|
| 入口 | 主动进入练舞 App | Feed 暂停自然触发 |
| 分析对象 | 完整练习视频 | 3–8 秒动作片段 |
| 目标 | 评价整支舞并长期记录 | 解决当前一个没看懂的卡点 |
| 输出 | 同屏对比、逐帧报告、统计 | 一个关键差异 + 三种针对性拆法 |
| 内容关系 | 用户自带老师视频 | 从短视频内容生态继续搜索 |
| 完成标准 | 看完分析 | 二练后卡点改善 |

## 5. 目标用户

第一阶段：16–30 岁，在短视频平台跟练手势舞、简单舞步和低风险技巧动作的普通用户。

不覆盖：专业舞蹈审美评分、整舞管理、课程表、视频云盘、健身伤病、高风险动作。

## 6. MVP 场景

- 3 个受控 Feed：Breaking 六步、手臂越顶路线、Tendu 脚尖伸展；
- 用户意图：说不清 / 手部 / 脚步 / 拍点；
- 用户从相册上传 3–8 秒模仿；
- 每个动作预置至少 5 条拆解内容标签；
- 诊断后返回 3 个不同拆解方式；
- 第二次上传验证关键差异是否下降；
- Demo 使用真实视频 `pause` 事件和 `currentTime`，方案层说明未来接入抖音 Feed。

## 7. 主流程

```text
Feed 刷到动作
→ 暂停 / 点击“分析 00:18.0 这一秒”
→ 查看动作阶段与三条专属拆解
→ 选择关注手部、脚步、拍点或让 AI 判断
→ 上传模仿
→ 姿态对齐与关键卡点定位
→ 生成状态搜索词
→ 召回背面 / 慢速 / 局部等三种拆解
→ 用户完成一个微练习
→ 第二次上传
→ 判断卡点是否改善
```

## 8. P0 功能

- Feed 卡片、真实暂停入口和时间点上下文；
- 用户关注部位表达；
- 视频上传和拍摄规范校验；
- MediaPipe、镜像校正、归一化、DTW；
- 节奏 / 路线 / 幅度诊断；
- 只输出一个主要卡点；
- 生成动作状态搜索词；
- 从标签库召回 3 种不同拆解方式；
- 关键帧对比图；
- 二次上传改善判断；
- 微信小程序、H5、Docker、Skill。

## 9. 明确不做

- 整支舞评分和逐秒长报告；
- 云端视频存储和练舞统计；
- 对任意导入动作承诺已标定准确率、多人和多机位；
- 社区、排行榜、课程管理；
- 真实全量抖音检索；
- 用 VLM 计算精确角度和时差。

## 10. AI / 算法分工

- OpenCV / FFmpeg：读取暂停点附近真实帧并生成本次对齐上下文；
- MediaPipe：提取暂停上下文和用户模仿的连续骨架；
- DTW + 规则：计算节奏、路线、幅度差异；
- 标签检索：按动作、卡点、身体区域、视角召回内容；
- 豆包 VLM：理解对比图语境、核验反馈并生成一句可执行表达；
- 后续 Agent：调用抖音内容检索、满足判断和追问。

## 11. 成功指标

比赛 Demo：

- 3 个动作参考配置成功；
- 合格视频人体覆盖率 ≥ 80%；
- 预设卡点 Top-1 稳定性 ≥ 80%；
- 每次至少召回 3 种不同拆解方式；
- 单次 CPU 分析目标 ≤ 25 秒；
- 二练闭环完整；
- 非现场评委无登录可体验。

产品指标：

- Feed 暂停入口点击率；
- 上传完成率；
- 搜索结果点击率；
- 二次练习率；
- 关键卡点改善率；
- 从卡点解决到模仿投稿的转化率。

## 12. 核心路演句

> 现有工具可以告诉你整支舞跳得怎么样；对拍解决的是刷视频时真实发生的那一刻——我就这一招没看懂，到底该搜哪一种教学。
