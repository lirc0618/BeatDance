# 90 秒 Demo 剧本 v2

**0–15 秒：真实行为**  
“刷到一个动作时，我们会暂停、慢放、去评论区求背面。问题不是没有教程，而是不知道自己这一招该搜什么。”

**15–28 秒：Feed 触发**  
在模拟 Feed 中暂停“手臂波浪”片段，点击“定格看手怎么走”，选择“手部没看懂”。

**28–48 秒：魔法时刻**  
上传第一次模仿。系统停在关键帧：

> “右臂启动早了约半拍。其他部位先别改。”

**48–64 秒：视觉搜索**  
结果不是长报告，而是三张内容卡：

- 三拍慢速分解；
- 手腕局部特写；
- 镜像背面跟练。

强调：这是依据用户的失败状态召回，不是按动作名搜热门教程。

**64–78 秒：验证**  
用户完成微练习并上传第二次：

> “关键偏差降低 38%。”

**78–90 秒：差异化**  
“已有产品擅长分析整支舞。定格教练只解决 Feed 里没看懂的半秒：定位卡点、搜索学法、验证学会，让内容消费自然变成模仿和投稿。”
